# Multi-User Checklist
A relatively powerful multi-user checklist program made with Raylib and LiteNetLib.
###### This project is _not_ made with Generative AI.

This is a small project I decided to make because none of the other ones were good, or had all the features I wanted.
## Roadmap

- [x] Easy to use multi-checklist view
- [ ] Autosave and recovery
- [ ] User permissions and management
- [x] Extensive theme customization
- [ ] Saving and loading local files
- [ ] P2P and Server support
- [ ] Grouping of checklists
- [ ] Realtime peer editing
- [x] Minimalist UI
- [ ] Dynamic DPI scaling
- [ ] Realtime log
